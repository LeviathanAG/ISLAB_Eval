# Documentation bundle

This folder contains downloaded official API pages for every external or
standard-library module imported by the new solved PYQ, Lab 5–8, and
standalone snippet files.  The mapping is in [`imports.md`](imports.md).

The HTML files are kept locally so the examples remain readable when internet
access is unavailable.  They are reference documentation, not copied source
code.  The project-specific helper API is documented in
[`crypto_helpers.md`](crypto_helpers.md).
