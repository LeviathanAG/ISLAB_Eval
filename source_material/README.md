The user-provided `Debrato2005/Sem_5_Labs` repository is cloned under
`source_material/Sem_5_Labs/`.  The Information Security PDFs are preserved in
that clone, with text extracts beside them for quick searching:

- `IS Lab Manual [1-4].pdf` / `.txt`
- `IS Lab Manual [5-6].pdf` / `.txt`
- `IS Lab Manual [7-8].pdf` / `.txt`

The directly referenced Lab 5–6 PDF is also saved as
`IS_Lab_Manual_5-6.pdf`.  The supplied repository contains no Lab 9–11 PDF;
therefore no unseen questions were invented.  The exact source-backed
solutions are in `solved_labs/lab05_hashing` through
`solved_labs/lab08_searchable_encryption`.

The repository's current `endsems/` directory is also preserved.  It contains
the author's expanded codebooks and reference menu scripts for the two
combined scenarios; our runnable solutions remain dependency-light and are
tested independently in this project.
